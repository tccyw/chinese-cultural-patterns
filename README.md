# 中华文化图样档案

一个面向公众、研究者和设计从业者的中华文化图样证据库。

- 公开展示地址：<https://tccyw.github.io/chinese-cultural-patterns/>
- 默认仓库：<https://github.com/tccyw/chinese-cultural-patterns>
- 技术栈：Astro + TypeScript + GitHub Pages

## 项目原则

本项目不是商标争议站，也不对具体案件作侵权判断。LV 与茉莉奶白相关讨论只作为“为什么需要公共文化图样档案”的背景专题。

第一版收录 12 个图样谱系：兽面纹、龙纹、凤鸟纹、云雷纹、回纹、柿蒂纹／四瓣花纹、莲花纹、忍冬纹、宝相花纹、缠枝花纹、八吉祥纹、蝙蝠寿字纹。

每个条目包含原创 SVG 重构图、名称、别名、时代谱系、载体门类、地域线索、历史说明、典型器物、来源等级和参考资料。

## 图像与资料边界

- 主图均为原创 SVG 抽象重构，用于表达结构特征。
- 不复制、不缓存、不热链不明授权的馆藏图片。
- 不展示、不复刻商业商标。
- 第三方资料只提供来源链接，不进入本仓库授权范围。

## 来源等级

- A：博物馆、考古机构、政府文化机构、学术论文。
- B：高校、出版社、专业数据库。
- C：主流媒体文化报道。
- D：社交平台、二手整理，仅作线索。
